Add EcoPrompt to Claude

  1. Open claude.ai → Settings → Connectors → Add custom connector.
  2. Name it EcoPrompt and paste this URL:
    https://…/mcp
  3. Turn it on in a chat from the tools menu, and ask: "Which model should I use for this?"

Using Claude Code? Run claude mcp add --transport http ecoprompt URL. ChatGPT, Cursor and other MCP-compatible tools accept the same URL.

What it tells you

"This is a simple task: Claude Haiku is good enough. Using it instead of Claude Opus uses about 96% less energy, saving ~2.3 Wh, ~7 mL of water and ~0.9 g CO₂ per query."

Privacy

EcoPrompt never stores your prompts. It keeps only an anonymous count: the task's difficulty level, the two model names and the estimated savings. No accounts, names or IP addresses.

Numbers are estimates based on published research (Google, Epoch AI, Hugging Face AI Energy Score, LBNL) and can differ from reality by 2–3× either way. Built at Rotterdam School of Management.
