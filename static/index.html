Add EcoPrompt to Claude

  1. Open claude.ai → Settings → Connectors → Add custom connector.
  2. Name it EcoPrompt and paste this URL:
    https://…/mcp
  3. Make it automatic: in Settings → Profile → personal preferences, paste:
    EcoPrompt is on: before answering any new task I give you, call EcoPrompt's recommend_model first, show me its model suggestion, and wait for my go-ahead before doing the task.
  4. Ask Claude for anything, e.g. "Write an essay on corporate restructuring". EcoPrompt suggests a right-sized model and waits for your go-ahead.

Using Claude Code? Run claude mcp add --transport http ecoprompt URL. ChatGPT, Cursor and other MCP-compatible tools accept the same URL.

What it tells you

"This is a simple task: Claude Haiku is good enough. Using it instead of Claude Opus uses about 96% less energy, saving ~2.3 Wh, ~7 mL of water and ~0.9 g CO₂ per query."

Privacy

EcoPrompt never stores your prompts. To measure its impact it keeps anonymous usage events: which tool was used, the AI app (e.g. Claude or Cursor), the task's difficulty level, the model names, whether you switched models, and the estimated savings. No accounts, names, emails or IP addresses, and events are deleted after 12 months.

Numbers are estimates based on published research (Google, Epoch AI, Hugging Face AI Energy Score, LBNL) and can differ from reality by 2–3× either way. Built at Rotterdam School of Management.
